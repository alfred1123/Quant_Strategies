## Prerequisites

| Target | Host | SSL | Roles |
|--------|------|-----|-------|
| **Prod / tunnel** | `127.0.0.1:5433` | `require` | `quant_app` + `quant_admin` (Aurora) |
| **Local dump** | `127.0.0.1:5432` | `disable` | `quant_admin` only until `dbctl bootstrap-roles` |

`pg_restore --no-privileges` does **not** recreate `quant_app` on :5432. Procedure DDL uses `DO $$ … IF EXISTS (pg_roles.quant_app)` so migrate **succeeds** without the role; grants apply once `quant_app` exists.

## Dry-run (review SQL)

`DB_TARGET` selects the port (see `.env` — default is `local` → :5432). Scripts **always** build `LIQUIBASE_COMMAND_URL` from host/port/sslmode; a hardcoded URL in `.env` is ignored.

```bash
# Local :5432 (default if .env has DB_TARGET=local)
DB_TARGET=local ./scripts/liquibase-verify.sh

# Aurora :5433 (SSM tunnel must be up)
./scripts/appctl.sh dev tunnel start
DB_TARGET=prod ./scripts/liquibase-verify.sh
```

## Apply

```bash
# Local :5432 (after restore)
./scripts/dbctl.sh bootstrap-roles   # optional but needed for quant_app grants
DB_TARGET=local ./scripts/liquibase-deploy.sh

# Aurora :5433 (manual — same files as prod EC2)
./scripts/appctl.sh dev tunnel start
DB_TARGET=prod ./scripts/liquibase-deploy.sh
# Then: POST /api/v1/refdata/refresh (bybit APP row)
```

## Post-apply checks

```sql
-- Table
SELECT * FROM information_schema.tables
 WHERE table_schema = 'core_admin' AND table_name = 'api_credential';

-- Procs
SELECT proname FROM pg_proc p
 JOIN pg_namespace n ON n.oid = p.pronamespace
 WHERE n.nspname = 'core_admin' AND proname LIKE '%api_credential%';

-- Bybit APP
SELECT app_id, name, display_name FROM refdata.app WHERE name = 'bybit';
```

`liquibase-deploy.sh` runs `core_admin` twice; `sql/GRANTS.sql` (`runOnChange=true` in baseline) still lists explicit `GRANT EXECUTE … TO quant_app` for credential SPs. Requires `quant_app` on the target (present on :5433, create via `bootstrap-roles` on :5432).
